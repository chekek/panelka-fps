# ПЯТЫЙ ЭТАЖ — панельный FPS

Одностраничный шутер от первого лица про поздний вечер в типовой панельке.
Ты — на 5-м этаже, в руках условный АК-47, под окнами спальный двор: парковка,
прямоугольные машины раз в минуту проезжают по дороге, тлеет мусорка, горит
вывеска «ПРОДУКТЫ 24». Перемещаться можно по своей трёшке, по межквартирному
коридору (лифт не работает) и по квартирам соседей — в пустой 52-й устроен тир.

## Запуск

Игра — **один файл** `index.html`. Никакой сборки не нужно.

- Локально: просто открой `index.html` в браузере (нужен интернет — three.js
  грузится с CDN).
- Или подними любой статический сервер: `python3 -m http.server 8000` →
  http://localhost:8000

## Деплой на GitHub Pages

1. Создай репозиторий (например, `panelka-fps`).
2. Загрузи туда `index.html` (и скриншоты по желанию).
3. Settings → Pages → Source: `Deploy from a branch` → ветка `main`, папка `/ (root)` → Save.
4. Через минуту игра будет доступна по адресу
   `https://<твой-ник>.github.io/panelka-fps/`

## Что можно делать

- Разбивать бутылки и банки (по квартирам и подоконникам) — +25/+15,
  зачистка всех целей даёт бонус +150, потом цели появляются заново.
- Стрелять по бумажным мишеням в 52-й — очки зависят от зоны попадания
  (до +50 за «десятку»).
- Бить окна: стёкла разлетаются, пуля летит дальше — во двор.
- Обстреливать машины (паркованные и проезжающие): срабатывает сигнализация,
  свет мигает, сигналит, машина «в панике» уезжает.
- Включать/выключать свет… шучу. Свет уже включён, телевизоры шумят,
  часы на кухне показывают реальное время, в окнах напротив кто-то
  досматривает вечер.

## Технически

- three.js r160 с CDN, всё остальное — процедурное: текстуры рисуются на
  canvas, звуки синтезируются через WebAudio (выстрелы, стекло, гильзы,
  сигнализации, шаги, шум города). Ни одного внешнего ассета.
- Коллизии — AABB, двери на петлях, гильзы с физикой, трассеры, декали
  от пуль, разбиваемое стекло.
- Рекорд хранится в localStorage.

### Кастомизация

В начале `<script type="module">` в `index.html` есть блок `CFG`:
`carMin/carMax` — интервал машин (сек), `rpm` — темп стрельбы,
`magSize` — ёмкость магазина, `walk/run/jumpV` — движение, `fov` — обзор и т.д.

**Управление мышью:** слайдеры в меню (чувствительность и громкость) —
настройки сохраняются в браузере.

## Совместимость

Нужен десктопный браузер с мышью и клавиатурой (Chrome / Firefox / Edge /
Safari). На тачскринах не играть — интерфейс предупредит.
